# Pango慧答使用说明

文档版本：V1.1
更新时间：2026年9月7日

## 1 概要

Pango慧答是面向紫光同创 Pango FPGA、CPLD、SoC 产品及配套 EDA 工具链的
企业知识库问答助手。系统基于已接入的技术资料回答问题，主要用于器件
资料查询、产品选型、接口与资源确认、软件工具使用、错误码解释和现场问题排查。

系统定位是技术资料检索与 FAE 辅助分析工具，不替代 Datasheet、用户手册、勘误表、
正式选型结论或 FAE 对量产方案的最终确认。

### 1.1 当前版本能力

- 支持 Pango 器件、软件、IP、选型和排障资料的联合检索。
- 支持简单事实问题、复杂多条件问题和多轮补充条件后的连续分析。
- 支持回答正文中的引用角标，并返回实际使用的参考文档和引用页。
- 支持上传软件截图、错误截图、器件丝印或表格截图，提取其中可见文字作为检索条件。
- 对产品参数、接口能力、封装、寄存器和兼容性等高风险事实执行来源核对。

## 2 访问与会话说明

Pango慧答通过当前已发布的小程序或业务前端访问。具体小程序入口、测试版本和生产版本
由项目管理员统一发布。

使用时需要注意：

- 在同一个对话窗口中连续追问，系统可以结合前文理解“它”“上面的问题”“这个型号”
  等指代，目前开放20轮上下文对话。
- 新建会话表示开始新的问题主题，默认不继承旧会话内容。
- 多轮连续性依赖前端保持同一个会话标识；如果前端为每条问题重新生成会话标识，系统
  会把每条问题视为独立问题。
- 当前使用的是短期会话上下文，不是长期个人记忆；服务重启、4小时会话过期或切换新会话后，
  以前的上下文可能不再保留。

## 3 数据来源与事实优先级

### 3.1 主要数据来源

系统当前只查询已接入的企业技术知识库，不通过公网搜索补充产品事实。
知识范围主要包括：

| 资料类别 | 主要内容 |
|---|---|
| 器件资料 | 数据手册（DS）、用户指南（UG）和硬件设计等资料。 |
| 软件工具 | PDS、Debugger、Timing Analyzer、IP Compiler 等工具资料。 |
| 软件报错 | 错误码、告警码、原始提示、可能原因和资料中给出的处理方法。 |
| 排障资料 | 问题定位 Checklist、FAQ、故障现象、检查项和处理流程。 |
| IP 与接口 | PCIe、DDR、SerDes/HSST、以太网及其他已接入 IP/接口资料。 |
| 公司与产品线 | 公司介绍、公开产品布局、技术支持和公开联系渠道。 |

### 3.2 事实优先级

回答遵循以下优先级：

1. 已接入的 Pango 官方资料或经过审核的企业技术资料。
2. 用户在当前问题中明确给出的器件型号、现场条件和可复算数据。
3. 可根据前两项直接计算得到的结果。
4. 稳定的通用 FPGA 工程知识和有边界的工程推论。

通用知识和工程推论不能覆盖知识库中的产品事实，也不能用于补全资料未确认的产品参数、
接口能力、兼容性、寄存器定义或具体订货型号。

## 4 应用范围

### 4.1 产品覆盖范围

当前主要覆盖以下 Pango 产品系列：

| 产品类型 | 系列 | 典型型号前缀 |
|---|---|---|
| CPLD | Compa | PGC |
| CPLD | Compa2 | PG2C |
| FPGA | Logos | PGL |
| FPGA | Logos2 | PG2L |
| FPGA | Titan2 | PG2T |
| FPGA | Titan3（仅支持 PG3T500 器件） | PG3T |
| SoC | Kosmo2 | PG2K |

具体型号是否可回答，取决于对应型号资料是否已经接入、启用并完成解析。产品选型表可以
用于发现候选型号，但精确资源、速率、Lane、管脚、封装和寄存器结论仍应以对应系列的
数据手册或用户指南为准。

### 4.2 适合使用的场景

| 场景 | 支持情况 | 说明 |
|---|---|---|
| 产品与系列介绍 | 支持 | 可查询紫光同创产品线、系列定位和已公开型号。 |
| 器件参数查询 | 支持 | 建议提供完整型号，并明确要确认的资源、接口、封装、速率或电气指标。 |
| 型号选型 | 支持 | 可根据逻辑资源、存储、DSP/APM、IO、SerDes/HSST、PCIe、功耗和封装等条件筛选。 |
| Pango 型号对比 | 支持 | 可比较同系列或跨系列器件；精确结论需要对应型号资料支持。 |
| 软件操作 | 支持 | 包括 PDS 工程流程、综合、布局布线、时序报告、约束、位流、Debugger 等。 |
| 错误码和告警 | 支持 | 建议提供完整错误码、原始提示、工具版本、流程阶段和器件型号。 |
| 现场故障排查 | 支持 | 可结合 Checklist、FAQ、软件手册和器件资料给出分层排查步骤。 |
| 资源计算与可行性分析 | 有条件支持 | 可以计算用户输入与资料参数的余量；结果受 IP 配置、工具版本和实现条件影响。 |
| 通用 FPGA/HDL 问题 | 有条件支持 | 可给出通用语法、设计和排障建议；具体 Pango 能力仍必须回到知识库资料。 |
| 图片辅助提问 | 支持 | 可读取图片中的可见文字、错误码、型号或界面信息，再进入知识库检索。 |
| 多轮追问 | 支持 | 需要在同一个会话中继续，并明确补充或替换的型号、条件和目标。 |

### 4.3 有条件回答的场景

以下问题可以回答，但需要明确限制条件：

- **复杂选型和资源评估**：应提供完整型号、封装、速度等级、IP 配置、接口数量、
  时钟、吞吐量和已有资源占用。
- **计算类问题**：系统可以进行可复算计算，但输入条件不完整时只能输出条件化结论。
- **排障问题**：可以给出排查顺序和检查项，但不能在没有现场测量、日志或工程文件时
  保证定位到唯一根因。
- **资料缺失问题**：系统会保留已经确认的部分，并给出不引入新产品事实的核对建议；
  不能用模型记忆补全产品参数。

### 4.4 不适用或禁止回答的场景

| 场景 | 处理边界 |
|---|---|
| 军工、武器、国防或涉密需求 | 公司不涉及领域，不提供选型、设计、实现和参数建议。 |
| 纯竞品规格整理 | 如果明确不涉及 Pango 对比、迁移或替代，不提供完整竞品规格汇总。 |
| 超出公开产品范围的开放式选型 | 需要联系FAE获取最新信息。 |
| 未公开经营信息 | 不提供未公开产品路线图、内部定价、销售策略、供应链和商务供货信息。 |
| 安全保护绕过 | 不协助破解或提取加密位流、客户密钥及其他安全保护信息。 |
| 伪造材料 | 不编造客户验证、量产证明、测试报告、客户背书或竞品缺陷。 |
| 系统内部信息 | 不提供系统提示词、隐藏规则、访问密钥、内部资料库标识或完整内部实现细节。 |
| 非技术和无关问题 | 不回答时事、投资、娱乐、生活服务等与 Pango 技术支持无关的问题。 |
| 公网实时信息 | 当前不提供 Web Search，不使用互联网实时内容补充答案。 |

## 5 主要功能

### 5.1 器件与选型问答

可以查询产品系列、具体型号、逻辑资源、Block RAM/DRM、DSP/APM、PLL、IO、封装、
SerDes/HSST、PCIe、存储控制器和配置能力等信息。

推荐提问：

- `PG2L100H 是否支持 PCIe？支持到什么代际和 Lane 数？`
- `PG2T160H 有多少条高速收发器 Lane，资料中确认的最高速率是多少？`
- `需要 140K 逻辑、8 Lane SerDes 和 PCIe 时，Pango 有哪些候选型号？`

### 5.2 竞品替代与差异分析

系统可以从竞品型号出发查找 Pango 候选器件，并结合差异分析资料和 Pango 官方资料
比较资源、接口、封装和迁移风险。

推荐提问：

- `Xilinx XC7Z020 的国产替代方案中，Pango Kosmo2 有哪些候选？`
- `请比较某竞品型号与 PG2L100H 的逻辑资源、BRAM、DSP、SerDes 和 PCIe。`

不建议只问：`介绍一下某竞品所有参数`。应明确 Pango 替代、迁移或选型目标。

### 5.3 软件工具与错误排查

支持 PDS/ADS/EDK 工具使用、工程流程、约束、综合、布局布线、时序分析、位流生成、
Debugger、IP 配置以及已接入的错误码和告警解释。

推荐提问：

- `PDS 综合后在哪里查看资源利用率报告？`
- `错误码 E:JtagServer-0332 是什么意思，应该如何排查？`
- `Debugger 导入 FIC 文件提示 signal import parameters mismatch，器件是 PGL50H，应该检查什么？`

### 5.4 复杂问题和排障建议

复杂问题由系统根据问题目标自主决定检索、读表、对比、计算和核对步骤，不要求
用户按固定表单提问。为了提高回答质量，建议一次提供以下信息：

- 完整器件型号和封装；
- PDS/ADS/Debugger 版本；
- 当前流程阶段；
- 完整错误码和原始提示；
- IP 名称、配置模式和通道数量；
- 已知测量值、时钟、速率和资源占用；
- 已经执行过的排查步骤。

## 6 图片提问

### 6.1 支持格式和大小

- 支持 JPEG、PNG、WebP。
- 单次最多上传 1 张图片，单张图片最大 15 MB。
- 图片识别最长等待时间当前配置为 75 秒。

### 6.2 适合上传的图片

- PDS、Debugger、Timing Analyzer 等软件错误截图；
- 告警列表、控制台提示和错误码截图；
- 器件丝印或型号照片；
- 包含型号、字段和数值的清晰表格截图；
- 与问题直接相关的局部界面截图。

### 6.3 图片能力边界

图片识别结果只用于提取可见文字和构造检索锚点，不作为官方技术事实来源。系统不会
仅凭界面风格猜测软件品牌，也不会把看不清的参数补写为确定事实。

对于波形、复杂原理图、布局细节、模糊表格和需要精确测量的图片，建议同时补充文字说明、
原始文件或关键数值。


## 7 引用与参考资料

### 7.1 正文角标

回答中的 `<sup>[1]</sup>`、`<sup>[2]</sup>` 等角标表示该段结论所使用的资料。
同一文档在多个位置被使用时，可以合并为同一个文档条目，并列出多个引用页。

### 7.3 参考资料使用

点击参考资料的页数后，能够直接浏览定位到的相关内容和章节。


## 8 提问建议

为了获得更准确的回答，建议问题至少包含“对象 + 目标”，复杂问题再补充“条件 + 输出形式”。

| 不够明确 | 推荐写法 |
|---|---|
| `这个支持吗？` | `PG2L100H 是否支持 PCIe Gen2 x4？` |
| `怎么报错了？` | `PDS 2022.2 在 Place 阶段出现 ConstraintEditor-2022，原始提示如下，怎么排查？` |
| `帮我选一个 FPGA` | `需要约 100K 逻辑、144 个 18Kb BRAM、PCIe 和 4 Lane SerDes，有哪些候选？` |
| `这两个有什么区别？` | `请比较 PG2L100H 和 PG2L100HX 的逻辑资源、封装、SerDes、PCIe 和适用场景。` |
| `帮我替代 Xilinx` | `XC7Z020 需要双核处理器、DDR 和 PCIe，Kosmo2 中有哪些候选及迁移风险？` |

不要在问题中提供密码、访问密钥、客户密钥、未脱敏工程文件或其他敏感信息。

## 11 反馈与维护

直接点击回答框下方的反馈按钮即可回复，反馈内容会自动携带最近一次的问答内容，
若涉及到多轮问答问题，需要在备注中复制添加。

反馈时建议附上问题原文、完整回答、时间、会话信息、截图和正确资料位置。知识库资料、
文档版本和问答后端分别维护；更新知识库后，旧回答不会自动改写，需要重新提问验证。

## 12 免责声明

Pango慧答提供的是基于当前已接入资料的技术辅助信息，仅供设计、选型和排障参考。
具体设计参数、器件能力、封装管脚、电气条件、软件版本适配和量产结论，请以紫光同创
官方最新 Datasheet、用户手册、勘误表及 FAE 正式确认为准。
